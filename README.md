Задание: Разработать экран профиля пользователя с настройками приложения на Kotlin Multiplatform с использованием MVVM архитектуры.

UI компоненты:
- Аватар пользователя (placeholder)
- Имя и email
- Раздел "Настройки":
  - Переключатель: Тёмная тема
  - Переключатель: Уведомления
  - Dropdown: Язык приложения
  - Slider: Размер шрифта
- Кнопка "Сохранить"
- Кнопка "Выйти из аккаунта"
- Диалог подтверждения выхода

Инструкция по запуску:
1. Скачайте APK из раздела Releases (по ссылке выше)
2. Скопируйте файл на устройство
3. Откройте файл через файловый менеджер и разрешите установку из неизвестных источников
4. Запустите приложение из меню установленных приложений
